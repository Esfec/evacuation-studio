起火点、火与烟的传播

火与烟沿拓扑跳数计算时序，不是物理扩散速度。传播率 0.1、风险系数 3、封闭系数 7 为原模型默认值。独立烟雾传播率是新增实验参数；留空保持原来的火烟同步。达到烟雾封闭时刻后浓度饱和为 1。

Agent 初始位置

手动放置可选起火房间与死端；不能选出口、关闭节点或超过房间容量。手动模式不使用自动起点距离筛选。按房间分配时三类人员由 seed 确定，逐个模式可精确控制。

步进、容量与策略参数

每步仍最多移动一跳。标称秒数改变时间标签，不换算步内物理过程。D1 的目标通道容量为基础值 ×2。自动起点无候选时，沿用原模型的 2 跳、1 跳降级筛选。

三类 Agent 的高级画像

base_speed 是现有模型的行动概率系数，不是米 / 秒。修改画像会改变研究假设；完整画像及哈希随运行保存。
